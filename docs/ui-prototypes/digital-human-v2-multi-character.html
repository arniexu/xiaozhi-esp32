Design Rationale

Fit for 320×240. The layout is a fixed three-band hierarchy: a 20px status strip (time, Wi-Fi, battery only), a ~196px face zone that owns roughly 80% of the screen, and a 22px single-line footer for state label plus one transcript hint. Nothing else competes with the character, which keeps the UI glanceable at arm's length on a small ST7789 panel.

The default digital human (光核 Light Core). It is built from three abstract layers rendered on one Canvas: a soft radial light field (the "aura"), two glowing capsule eyes with an inner core and highlight (the identity), and a voice element below them (waveform when speaking, level bars when listening, a quiet smile arc at rest). It is deliberately not a photo and not an emoji; the capsule-pair silhouette plus aura is the recognizable product mark. The other four characters reuse the same frame pipeline (state interpolation, blink, reduced-motion) with their own silhouette, face language and state motion.

Motion is semantics, not decoration. Idle breathes and blinks; listening shows input level cues; thinking drifts the gaze or orbiting dots; speaking drives a voice element; connecting sweeps an arc and blinks the Wi-Fi icon; upgrading reports progress with a percent readout; error collapses the eyes, adds jitter and glitch accents. All animation stops under prefers-reduced-motion, which renders one static representative frame per state.

LVGL mapping. Status strip = one lv_obj flex row with lv_label + two drawn icons; face zone = a single lv_canvas (320×196, RGB565) or a custom draw callback driven by a 30fps lv_timer, using the same primitives (rounded rects, arcs, polygons, radial gradient approximated by layered fills); footer = one lv_label with LV_LABEL_LONG_SCROLL as fallback; the palette maps 1:1 to lv_color_hex constants; states map to a ui_state_t enum with a dispatch table, and characters map to a ui_character_t table of draw callbacks - the centralized STATES and CHARACTERS data in this file is the direct template for those tables. Reduced-motion maps to a build-time flag that freezes the timer.

Constraints honored. Near-black base with warm white, teal, coral red and a small lemon accent; no purple gradients, no glassmorphism; corner radius <= 8px everywhere; letter-spacing: 0; local CJK font stack only; zero external assets, fonts, images or SVG.

Character Directions

Five original abstract directions, distilled from 2025 market-preference research: young users value emotional resonance, self-reward (悦己), individuality and domestic original IP; young professionals prefer light, healing companions while mildly rebellious, curious "not-so-well-behaved" traits are rising; AI companion hardware needs a sustained sense of interaction, so every direction animates all seven states.

  • 光核 Light Core - calm, neutral tech companion; emotional value: quiet trust, reliability, focus. LVGL complexity: medium - radial glow approximated by layered fills, capsule eyes are rounded rects, one waveform polyline.
  • 云团 Cloud Puff - soft healing direction for stressed young professionals; a squashy abstract cloud (not any concrete animal) that comforts through breath and lean. LVGL complexity: low - circle fills, one capsule base, arcs and short strokes only.
  • 电波豆 Wave Bean - playful little rebel for individuality and self-expression; asymmetric winking face, antenna spark, zigzag mouth. LVGL complexity: low-medium - one ellipse body, lines, small cross sparks.
  • 糯米团 Mochi Blob - food-mimic softness and self-reward; emotion reads purely through squish, stretch and bounce of one blob. LVGL complexity: low - a single ellipse with animated radii plus dots and arcs.
  • 山灵 Mountain Spirit - modern Chinese-aesthetic original direction; layered abstract peaks, a small gold disc and drifting mist, no concrete mythological symbols. LVGL complexity: low - three polygon fills, strokes and one circle.

All five are original trend explorations derived from abstract preference data. They do not depict, reference or imitate any existing copyrighted character or IP.
