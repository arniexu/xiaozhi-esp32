## 3. 接口说明

### 3.1 登录接口

#### 3.1.1 接口描述

用于登录获取token 及token 颁发者

#### 3.1.2 接口定义


| 字段说明   | 参数类型    | 备注                      |
| ---------- | ----------- | ------------------------- |
| 用户名     | String 类型 | 必填                      |
| 密码       | String 类型 | 必填                      |
| 登录类型   | String 类型 | 必填，固定值：“1”       |
| 系统标识   | String 类型 | 必填，固定值：electric    |
| 成功标识   | String 类型 | SUCCEED 成功，FAILED 失败 |
| 返回时间戳 | String 类型 | 接口返回时间戳            |
| 数据       | Object 类型 | 具体结构见下表            |
| token      | String 类型 | token                     |
| tokenIss   | String 类型 | token 颁发者              |

#### 3.1.3 请求数据示例

- **Url&Params**：https://gateway.wuzheng.com.cn/common/user/user/common_login
- **Body**：

```json
"providerSys": "electric", 
"loginName": "account01", 
"loginPwd": "password01", 
"loginType": "1"
```

#### 3.1.4 返回数据示例

```json
"result": "SUCCEED", 
"timestamp": "1611038843539", 
"data": { 
"tokenIssuer": "electric", 
"token": "eyJhbGciOiJSUzI1......"
```

### 3.2 车辆实时数据接口

#### 3.2.1 接口描述

用于查询车辆实时数据，包含车速、位置、累计里程、剩余续航里程、SOC、门锁状态、门状态

#### 3.2.2 接口定义


| 字段说明   | 参数类型    | 备注                                                                                                                          |
| ---------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 签名       | String 类型 | 必填，任意签名                                                                                                                |
| 请求时间戳 | String 类型 | 必填，当前时间戳                                                                                                              |
| 请求 ID    | String 类型 | 必填，任意中文或字母                                                                                                          |
| token      | String 类型 | 必填，登录获取的 token                                                                                                        |
| 颁发者     | String 类型 | 必填，登录获取的 tokenIssuer                                                                                                  |
| VIN 码     | String 类型 | 必填，车辆 VIN                                                                                                                |
| 成功标识   | String 类型 | SUCCEED 成功，FAILED 失败                                                                                                     |
| 返回时间戳 | String 类型 | 接口返回时间戳                                                                                                                |
| 数据       | Object 类型 | 实时数据，具体结构如下                                                                                                        |
| vin        | String 类型 | 车辆 VIN 码                                                                                                                   |
| gatime     | String 类型 | 最新数据采集时间                                                                                                              |
| emiles     | Number 类型 | 续航里程                                                                                                                      |
| soc        | Number 类型 | 电量                                                                                                                          |
| position   | String 类型 | 位置                                                                                                                          |
| lksts      | String 类型 | Bit1-0：左前门锁状态；Bit3-2：右前门锁状态；Bit5-4：左后门锁状态；Bit7-6：右后门锁状态；0：闭锁，1：解锁，3：无效             |
| lksts1     | String 类型 | 左前门锁，0：闭锁，1：解锁，3：无效                                                                                           |
| lksts2     | String 类型 | 右前门锁，0：闭锁，1：解锁，3：无效                                                                                           |
| lksts3     | String 类型 | 左后门锁，0：闭锁，1：解锁，3：无效                                                                                           |
| lksts4     | String 类型 | 右后门锁，0：闭锁，1：解锁，3：无效                                                                                           |
| doorsts    | String 类型 | Bit1-0：左前门开关状态；Bit3-2：右前门开关状态；Bit5-4：左后门开关状态；Bit7-6：右后门开关状态；0：关闭，1：开启，3：表示无效 |
| doorsts1   | String 类型 | 左前门开关，0：关闭，1：开启，3：无效                                                                                         |
| doorsts2   | String 类型 | 右前门开关，0：关闭，1：开启，3：无效                                                                                         |
| doorsts3   | String 类型 | 左后门开关，0：关闭，1：开启，3：无效                                                                                         |
| doorsts4   | String 类型 | 右后门开关，0：关闭，1：开启，3：无效                                                                                         |

#### 3.2.3 请求数据示例

- **Url&Params**：https://gateway.wuzheng.com.cn/vehicle/data/parter/api/ai/get/real/times?sign=sign&timestamp=1611038987063
- **Headers**：
  - X-Request-Id : 1
  - Authorization : bGciOiJSUzI1NiJ9.eyJYLVVzZXItUm9sZXMiOlt7In...

- **Body**：

"vin" :"LZ0V1JF18J2000088" 
}
```

"tmiles": 199205.0, 
"emiles": 232.9, 
"speed": 0.0, 
"soc": 97, 
"lksts": "01010101", 
"lksts1": "解锁", 
"lksts2": "解锁", 
"lksts3": "解锁", 
"lksts4": "解锁", 
"doorsts": "00000000", 
"doorsts1": "关闭", 
"doorsts2": "关闭", 
"doorsts3": "关闭", 
"doorsts4": "关闭", 
"position": "四川省遂宁市船山区广德街道遂宁宽窄印务有限责任公司" 
}
```

### 3.3 车辆充电统计接口

#### 3.3.1 接口描述

用于获取车辆充电统计数据，支持按日和按月查询

#### 3.3.2 接口定义


| 字段说明         | 参数类型    | 备注                         |
| ---------------- | ----------- | ---------------------------- |
| 签名             | String 类型 | 必填，任意签名               |
| 请求时间戳       | String 类型 | 必填，当前时间戳             |
| 请求 ID          | String 类型 | 必填，任意中文或字母         |
| token            | String 类型 | 必填，登录获取的 token       |
| 颁发者           | String 类型 | 必填，登录获取的 tokenIssuer |
| VIN 码           | String 类型 | 必填，车辆 VIN               |
| 开始日期         | String 类型 | 必填，YYYYMMDD，如20250818   |
| 结束日期         | String 类型 | 必填，YYYYMMDD，如20250818   |
| 成功标识         | String 类型 | SUCCEED 成功，FAILED 失败    |
| 返回时间戳       | String 类型 | 接口返回时间戳               |
| 提示信息         | Object 类型 | 具体结构如下                 |
| 电耗             | Number 类型 | 耗电量，单位 kwh             |
| tmiles           | Number 类型 | 行驶里程，单位 km            |
| electric Hundred | Number 类型 | 百公里耗电量，单位 kwh/100km |
| recharge Count   | Number 类型 | 充电次数                     |

#### 3.3.3 请求数据示例

- **Url&Params**：https://gateway.wuzheng.com.cn/vehicle/analysis/bos/chargeStatistics?sign=sign&timestamp=1611038987063
- **Headers**：
  - X-Request-Id : 1
  - Authorization : bGciOiJSUzI1NiJ9.eyJYLVVzZXItUm9sZXMiOlt7In...
  - X-Token-Issuer : electric
- **Body**：

```json
"vin" : "LZ0V1JF18J2000088", 
"dateBegin": "20250801", 
"dateEnd": "20250818"
```

#### 3.3.4 返回数据示例

```json
"result": "SUCCEED", 
"timestamp": "1755487147834", 
"data": { 
"electric": 813, 
"tmiles": 8518.125, 
"electricHundred": 9.54, 
"rechargeCount": 10
```

### 3.4 车辆车门控制下发接口

#### 3.4.1 接口描述

车辆车门控制指令下发

#### 3.4.2 接口定义


| 字段说明     | 参数类型     | 备注                                |
| ------------ | ------------ | ----------------------------------- |
| 签名         | String 类型  | 必填，任意签名                      |
| 请求时间戳   | String 类型  | 必填，当前时间戳                    |
| 请求 ID      | String 类型  | 必填，任意中文或字母                |
| token        | String 类型  | 必填，登录获取的 token              |
| 颁发者       | String 类型  | 必填，登录获取的 tokenIssuer        |
| VIN 码       | String 类型  | 必填，车辆 VIN                      |
| 协议         | String 类型  | 必填，GB32960                       |
| 指令类型     | Number 类型  | 必填，10：车门设防                  |
| 下发时间戳   | String 类型  | 必填，13 位时间戳                   |
| 下发参数     | Object 类型  | 具体结构如下                        |
| 下发门锁参数 | Object 类型  | 具体结构如下                        |
| 左前门锁     | Number 类型  | 1：一键设防，2：一键撤防            |
| 左后门锁     | Number 类型  | -                                   |
| 右前门锁     | Number 类型  | -                                   |
| 右后门锁     | Number 类型  | -                                   |
| 后备门锁     | Number 类型  | -                                   |
| 成功标识     | String 类型  | SUCCEED：调用成功，FAILED：调用失败 |
| 返回时间戳   | String 类型  | 接口返回时间戳                      |
| 数据         | Boolean 类型 | true：下发成功，false：下发失败     |

#### 3.4.3 请求数据示例

- **Url&Params**：https://gateway.wuzheng.com.cn/vehicle/control/bos/issue_terminal_control_command
- **Body**：

```json
"vin": "LZ0B9JF20K1076111", 
"protocolType": "GB32960", 
"issueTime": 1755483288497, 
"cmdType": 10, 
"parameter": { 
"lockParameter": { 
"frontLeftLock": 1, 
"rearLeftLock": 1, 
"frontRightLock": 1, 
"rearRightLock": 1, 
"trunkLock": 1
```

#### 3.4.4 返回数据示例

1. **指令下发成功**：

```json
"result": "SUCCEED", 
"timestamp": "1753163753905", 
"requestId": "123", 
"data": true 
}
```

2. **指令下发失败**：

```json
"result": "SUCCEED", 
"timestamp": "1753163753905", 
"requestId": "123", 
"data": false 
}
```

3. **程序异常报错**：

```json
"result": "FAILED", 
"timestamp": "1753163753905", 
"requestId": "123",
```
